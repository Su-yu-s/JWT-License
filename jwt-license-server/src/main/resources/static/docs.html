API 文档

客户端 SDK 对接的授权验证接口说明，以及后台管理接口概览。

客户端授权流程

SDK 集成的标准交互链路。

1输入授权 Key
→
2请求激活接口
→
3获取 JWT
→
4本地验证签名
→
5心跳保活

激活接口

客户端发送授权 Key 到服务端验证并获取 JWT。

项目 说明
方法 POST
路径 /api/v1/license/activate
请求头 Content-Type: application/json
X-Machine-Hash: <设备唯一标识>
请求体 
{
  "license_key": "DEMO-7X2K-9MBQ-PF4R-W8TN",
  "product_id": "desktop-client",
  "sdk_version": "v2.4.1"
}
成功响应 
{
  "access_token": "eyJhbGciOiJSUzI1NiIs...",
  "token_type": "Bearer",
  "expires_in": 2592000,
  "jwt_expires_at": "2026-12-31T23:59:59+08:00"
}
错误响应 
{
  "detail": "授权 Key 不存在或已被禁用"
}

心跳接口

客户端定期调用以维持会话活跃。

项目 说明
方法 POST
路径 /api/v1/license/heartbeat
请求头 Authorization: Bearer <JWT token>
成功响应 
{
  "status": "ok",
  "remaining_seconds": 86400
}
失败响应 
{
  "detail": "Token 已过期或无效"
}

JWT 结构

服务端签发的 JWT 包含以下声明字段。

声明 类型 说明
sub string 授权 Key 的唯一 ID
aud string 产品 Audience，客户端需匹配
machine_hash string 设备指纹哈希
iat number 签发时间戳
exp number 过期时间戳
kid string 使用的签名密钥 ID
